# Editing

Gallery supports cropping, rotation, mirroring and adjustments for photos, and non-destructive video trimming. Ordinary edits leave the original file untouched. The web photo editor also offers explicit file-saving options: save a new image or overwrite the original.

## Photo Editing

Gallery can apply these edits to a photo:

- Cropping
- Rotation
- Mirroring
- Adjustments (exposure, contrast, saturation, invert)

## Adjustments

A toggle at the top of the editor panel switches between **Edit** (adjustment sliders) and **Crop** (the aspect-ratio grid). Both are part of the same edit, so you can crop and adjust an image in a single save.

The **Edit** panel provides four controls:

- **Exposure** — brightens or darkens the image
- **Contrast** — increases or decreases the difference between light and dark areas
- **Saturation** — increases or decreases color intensity; fully desaturating produces a grayscale image
- **Invert** — a toggle that inverts colors, useful for viewing scanned film negatives as positives

Double-click (or double-tap) a slider to reset just that value to its default. Adjustments are matched to the same formulas as the CSS `filter` property, so the live preview while dragging a slider is an exact preview of the saved result, not an approximation.

Adjustments are made in the web app. The mobile app shows adjusted photos but cannot change the adjustment yet; cropping, rotating or mirroring a photo there keeps it. [Switching back](/guides/switch-back-to-immich) removes adjustments, which have no equivalent there, and keeps the other edits.

## Saving an Image File

The web photo editor can render the current crop, rotation, mirroring and adjustments into an image file:

- **Save as a new image** creates a separate asset. The source file and its non-destructive edits remain unchanged. This requires both permission to edit the source and permission to upload images.
- **Overwrite original** replaces the source file and updates the existing asset. This is destructive: reverting the asset's edits afterwards cannot restore the previous file. Take a backup before using it.

Overwriting an external-library image requires a writable file and directory inside the server container. Read-only external libraries can still be used as the source of a new image. JPEG, PNG and WebP output keep their supported format. Other static formats are saved as PNG when the decoded image contains transparency, or JPEG otherwise; the filename and extension are updated to match the output. Live Photos, GIFs, SVGs and panoramas do not support file saving.

Both options apply adjustments and geometry together. After overwriting, the already-rendered adjustment and crop records are cleared so the new original is not adjusted twice. Capture dates, GPS and EXIF metadata are preserved; thumbnails and analysis results are rebuilt for the saved image.

A failed or interrupted save retains its recovery journal. Let Gallery finish or recover pending saves before rolling back or [switching back to the upstream server](/guides/switch-back-to-immich). The switch-back script refuses to discard unfinished recovery records. After the migration-ledger split, switching to an earlier Gallery image alone is not a safe rollback; follow the [rollback guide](/install/upgrading#rolling-back-to-an-earlier-release).

## Video Trimming

Trimming a video is non-destructive too. Open the editor on a video and a trim interface replaces the photo editor:

- A timeline scrubber sits below the video, with draggable in and out handles that pick the portion to keep.
- The sidebar shows the trimmed duration, in/out time inputs, and set in/out buttons.
- Press **I** to set the in point and **O** to set the out point at the current playback position. **Space** toggles play/pause within the trimmed region.

### How It Works

Trimming uses FFmpeg stream copy (`-c copy`), so:

- Nothing is re-encoded. A trim finishes in seconds no matter how long the video is.
- Video and audio quality are identical to the original.
- Cut points land on the nearest keyframe, so the real start and end can sit a few frames away from the position you picked.

After saving, the video player serves the trimmed version. The thumbnail and displayed duration update on their own.

### Re-trimming

You can re-open the editor on a trimmed video and adjust the range. The timeline still shows the full original duration, so you can widen the trim back toward the original length at any point. A trim never locks you into the shorter version.

### Limitations

- Trimming is not available for videos in external libraries.
- With **Real-time Transcoding** enabled, a trimmed video plays the trimmed file directly, without quality switching.
- Cuts are not frame-accurate; the precision depends on keyframe spacing.
- Crop, rotate and mirror are image-only.

## Quick Rotate

You can rotate images without opening the full editor, from two places.

### Asset Viewer

When viewing a single image, a **Rotate Right** button appears in the toolbar. Additional rotation options (**Rotate Left** and **Rotate 180°**) are available in the **More** menu (three dots).

The rotation is applied immediately and both the viewer and timeline thumbnail refresh in place.

Rotations are cumulative: rotating right twice gives a 180° rotation. When the total reaches a full 360°, the edit is removed and the asset goes back to its original orientation.

### Multi-Select (Batch Rotate)

When selecting multiple assets in the timeline, you can rotate them all at once:

1. Select the images you want to rotate
2. Open the context menu (three dots)
3. Choose **Rotate Right**, **Rotate Left**, or **Rotate 180°**

Only images are rotated; videos are skipped. Timeline thumbnails update once the server finishes processing each asset.

## Download

When you download an edited asset, Gallery provides the edited version of the asset by default. However, you can choose to download the original version if needed.

## Reverting Edits

To revert an ordinary non-destructive edit back to the asset's current original (not a file replaced by **Overwrite original**):

1. Open the asset in the viewer
2. Open the editor
3. Remove all edits and save

The asset is restored to its original state and the thumbnail updates on its own.

## Edited Asset Handling

Edits carry through the rest of Gallery:

- Thumbnails update after an edit, with no page refresh.
- Video playback serves the trimmed version of a trimmed video.
- The duration shown on a video thumbnail reflects the trimmed length.
- Album thumbnails use the edited version of an asset when one exists.
- Person thumbnails show the original, unedited preview, which keeps face recognition accurate.
- Downloads serve the edited version by default, with an option to take the original.
